# Concept artwork and high-level requirements

The three JPG files in this directory are visual concepts, not dimensioned CAD designs. Their current proposed requirements are indexed in [the Draw.io baseline](../CAS/Drawio/README.md). Every current image maps to one concept-specific diagram plus the common requirements diagram.

Do not infer dimensions, protection level, endurance, propulsion technology, certification or implemented autonomy from artwork. Numerical parameters are open engineering decisions tracked in each diagram.
